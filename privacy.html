Privacy policy

piserver-backup is a private tool used only by its owner to back up their own home server to their own Google Drive.

  • It uses the Google Drive scope drive.file: it can only see and change files it created itself. It cannot read any other files in the Drive.
  • Backups are encrypted on the server before upload. No data is sent anywhere else, sold or shared with anyone.
  • It does not collect, store or process data about any other person, and it has no other users.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Questions: open an issue on this site's GitHub repository.
